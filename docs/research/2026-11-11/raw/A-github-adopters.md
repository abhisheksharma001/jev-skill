# A. GitHub adopters of Jev (TypeSafe System One)

As of 2026-11-11 (read 2026-11-11 17:30-18:10 IST). All sources read LIVE via `gh api` (README raw, issues, repo metadata). Nothing here comes from model memory.

Method: `gh search code` for 11 identifiers (`api.typesafe.ai`, `typesafe-sdk`, `typesafe_sdk`, `@typesafe-ai/sdk`, `langchain-typesafe`, `TYPESAFE_API_KEY`, `api.typesafe.ai/v1/systemone`, `typesafe/jev`, `jev-1.13`, `jev-1.14`, `systemone typesafe`; 100-result cap each, `jev-latest` search hit the 403 rate limit and was not retried) gave 481 unique repos. After removing forks and empty repos, that is about 478 candidates. Many are noise (name collisions, awesome-lists, docs, SDK ports). I read READMEs and issues of about 80 of them and kept the 38 below that make a concrete decision with Jev. GitLab (API title search "jev") returned only 0-1 star repos (see leads). Codeberg API returned non-JSON, so not checked. Two community catalogs claim far more: `heyjunpenn/awesome-jev` says "992 open-source projects" (not verified).

Vendor repos (excluded from the table, noted only): `typesafe-ai/typesafe-sdk-python` (313 stars, latest release v0.7.5 on 2026-10-14), `typesafe-ai/typesafe-sdk-js` (285 stars, v0.7.0 on 2026-10-14), `typesafe-ai/skills` (2,892 stars, last push 2026-10-23), `typesafe-ai/system-one-adapter-python` (412), `typesafe-ai/WorkflowEvals` (21), `typesafe-ai/typesafe-public-examples` (13, issues disabled), `typesafe-ai/n8n-nodes-typesafe-ai` (15, pushed 2026-11-09; official n8n node). Jev 1.14.0 exists and adds the `box` primitive (python release notes).

Independence key: I = independent individual/community; C = commercial third party with a product at stake (treat as partner-ish); V = vendor; P? = possibly partner-derived (unverified).

## Patterns seen across adopters

1. **Coding-agent plumbing is the dominant adopter category** (mu, winnow, quicksilver, pi-jev, jev-gateway, jev-router, Canny, JevPromptShield, jevmem, jgrep, jev-review, fallow-verdict): context filtering, tool-call gates, model routing, memory writes. Most are by individual developers, many 100-700 stars within two months.
2. **Fail-open is the near-universal fallback**: pi-jev, jev-gateway, jev-router, mastra moderation, reply_gate (default open), mu. Exceptions: JevPromptShield defaults to ASK, `fail_mode: block` optional.
3. **Thresholds always live in code, and several authors calibrated them by hand**: pi-jev 0.90 (destructive) and 0.85 (beyond_scope) because requested `sed -i` scored 0.85; classifier.dev re-asks below 0.7; labeler 0.8; voice-browser `complete >= 0.6`.
4. **Calibration is repeatedly found optimistic**: monumei (1.14, n=2,319): 0.9+ bucket 98.9% mean confidence vs 84.3% accuracy; classifier.dev (n=400): >= 0.9 right 82%. Consistent with the fit-map line "right 64% in its 80-95% band".
5. **Cascades with a bigger model are what independent authors actually build** (typesafe-cascade, classifier.dev smart tier, mu `mude,jev`), reported together with escalated share (10.9% to 27.2%).
6. **Decomposition into several atomic questions in one request** is standard (pi-jev 4 questions, voice-browser about 12, mubench, jevals).
7. **Version drift is real and confirmed independently**: sammy143 shows 1.14 vs 1.13 swing of +41.6 on a phishing variant and -3.9 on RAGTruth, release notes silent on both. Authors pin `jev-1.13.0` (labeler, voice-browser, trolley-bench).
8. **Cost and latency claims reproduce**: p50 about 244-330 ms (jevals 244, voice-browser 300, JevHarness 269, jev-guardrails 177 median), about $0.00006-0.0002 per call. Cost per decision is NOT only a per-million price: sammy143 finds Jev bills about 38% more tokens than another model for identical short inputs.
9. **A rival ecosystem now exists** and several adopters are model-agnostic (jevals, mu, ThinkFlowLab, fastbrowse): Laya, Kev, Clef, d1, Eikos, SubQ Snap, Solar Decide, mude, Decision-1. On zero-shot-ie-bench Jev 1.14 is mid-table.

## Contradictions or updates against the existing fit-map (as of 2026-11-11)

- **Skill routing roster size**: fit-map says "oh-my-pi 0 misses at 39 skills". OrMizL (n=81 turns, 84-skill roster, upstream thresholds) found top-1 53.6%, abstain 36.2%, wrong 10.1%. Precision when it answers 84.1% (37/44). Split by roster size/harness, not a refutation, but the GOOD verdict should say "at ~40 skills; abstains heavily at ~84".
- **Version**: fit-map invariants pin 1.13.0; 1.14.0 exists (SDK `box`, released about 2026-10-14). 1.14 vs 1.13: independent data shows RAGTruth (grounding) regressed 3.9 pts and a phishing variant jumped 41.6 pts. The fit-map grounding entry (HYBRID) is probably 1.13-specific.
- **Resume screening BAD**: fit-map cites "69% preference for one of six equivalent options". bias-bench (n=1,824 evals, one domain, name-swap) finds Jev's white-minus-black callback gap 0.0pp, smaller than four LLM screeners. Does not make it safe (regulated; different test), but the "BAD, no fairness audit" wording needs "one name-swap audit exists".
- **In-call voice**: fit-map marks end-of-turn/barge-in UNKNOWN and says partial transcripts fell to `other`. voice-browser puts an "is the command complete?" question on every partial transcript with 200 ms debounce and a code policy; 34/34 fixtures, p50 about 300 ms. It is a browser-command use case, not a phone agent, and fixtures are the author's own. Update to UNKNOWN-with-one-working-demo.
- **Agent progress / permission questions**: mu's mubench puts Jev 1.14 at 61.6 on "progress and completion" (mude 86.6) and about 53 on "permission approval". Agrees with fit-map HYBRID for agent control and "never ask Jev to self-assess".
- **Prompt-injection UNKNOWN**: new independent repro: typesafe-sdk-python issue #24 (2026-10-22, closed) shows a fake blank `STATE:` header appended to state flips a `choice` to `says_nothing` when the question says "the state" but not when it names a field. Supports the fit-map "fake delimiters weakest" and the "name a field" advice.
- **Gateway gotcha not in fit-map**: Cloudflare returns HTML 403 (never reaching the API) when `state` text contains a `curl ... https://...` command (typesafe-sdk-js issue #15, 2026-09-23, jev-1.13.0, still open as of 2026-11-11; labeler-action README documents the same).
- **`choice` is not always the argmax**: typesafe-sdk-python issue #15 (35 responses, 2026-09-23, jev-1.13.0): `choice` exactly 0.01 below another option's probability in near-ties (rounding then renormalising). Compute argmax yourself on near-ties; marked closed.
- **Output tokens free**: unresolved question in typesafe-ai/skills #12 (a plugin prices output at $0.13/Mtok). Not confirmed either way.
- **Trading BAD**: a live Jev trading bot exists (227 stars) but publishes no PnL in the README; nothing contradicts the independent backtest.
